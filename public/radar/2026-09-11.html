1 GPT-Live-1: מודל קול full-duplex ב-API
הקול שמפעיל את ה-Voice של צ'אטGPT, עכשיו זמין ב-API — $0.05 לדקה. אזהרת עברית בפנים.
מאומת מול openai.com אין עברית עדיין $0.05 / דקה

מה זה באמת

מודל הקול שמפעיל את ה-Voice של צ'אטGPT, זמין מהיום גם ב-API. full-duplex = הוא מאזין ומדבר באותו זמן, שיחה אחת רציפה בלי "תורות". עד היום ב-API היה GPT-Realtime התורני; הדגם הזה מחליף את הגישה.

  • מחיר: $0.05 לדקת שיחה. זה רק שכבת הקול. החשיבה מאחורה (מודל טקסט שמחובר אליו) מתומחרת בנפרד לפי טוקנים.
  • הפרעות ורעש: מודל אחד מעבד גם אודיו נכנס וגם יוצא, בלי שרשרת של STT ← LLM ← TTS. חברת Speak דיווחה על כמעט 80% פחות קטיעות מול מערכות תורניות.
  • Delegation: המודל מעביר חשיבה עמוקה וקריאות כלים למודל backend (Astra או מודל אחר), והשיחה ממשיכה בזמן שהעבודה רצה ברקע.
  • תמיכה בטלפוניה אמיתית ובשיחות ארוכות.

מה השתנה

30 נקודות שיפור ב-Full Duplex Bench מול GPT-Realtime-2.1, ומקום ראשון ב-Tau3 (מבחן סוכני קול) כשמצמידים לו Astra כ-backend.

אזהרת העברית המלאה: ברשימת הקולות הרשמית בתיעוד יש כרגע רק אנגלית ופורטוגזית. בדף ההשקה OpenAI כותבים שהמודל אופטמז ל"שפות הנפוצות" ושבשפות מסוימות יהיה מבטא לא-ילידי או פערים בשטף. עברית לא צוינה בשום מקום.

מה זה נותן לך

מענה

זה הלב של המוצר שלך. שיחה רציפה עם הפסקות טבעיות בלי לתפור תשתית בעצמך. אבל קודם — בדיקת עברית (ראה אזהרה למעלה).

חשבון

שעת שיחה = $3 לשכבת הקול + עלות מודל ה-backend. עם backend זול זה נשאר במספרים נמוכים. עם Astra ($50 למיליון טוקנים פלט) זה כבר סיפור אחר.

פודקסטו

לא רלוונטי. פודקסטו הוא TTS באצווה, לא שיחה חיה.

ראיונות

"בניתי סוכן קולי full-duplex בעברית על ה-API שיצא השבוע" זה משפט פתיחה.

2 Agents API של OpenAI: התשתית של Codex כשירות
בטא ציבורית: API שמריץ סוכנים בענן על אותו harness שמפעיל את Codex. בלי עמלה נוספת.
מאומת מול openai.com רק טוקנים + כלים

מה זה באמת

OpenAI פתחה אתמול בטא ציבורית (לכולם) של API שמריץ סוכנים בענן על אותה תשתית (harness) שמפעילה את Codex. קריאת API אחת עם משימה, מודל, כלים וסביבה — והם מנהלים את השאר:

  • הקשר ארוך: compaction אוטומטי כשמתקרבים לגבול חלון ההקשר, בלי שתכתוב את זה בעצמך.
  • סוכני-משנה: multi_agent מובנה — הסוכן הראשי מפצל עבודה לסוכנים במקביל ומרכז תוצאות.
  • סביבה: sandbox מנוהל אצל OpenAI, תשתית משלך, או שותפים (Cloudflare, Vercel, Modal ועוד).
  • כלים: תמיכה מובנית ב-MCP, פונקציות מותאמות, web search, ו-tool search שטוען הגדרות כלים לפי צורך כדי לחסוך טוקנים.

מה השתנה

עד היום בנית את התשתית הזו לבד (או לקחת פריימוורק). עכשיו OpenAI מוכרת אותה. אין עמלה נוספת: משלמים רק טוקנים וכלים.

מה זה נותן לך

פודקסטו

ה-API תומך ב-MCP מובנה (server_url + transport http, בדיוק הצורה שהגדרת בשרת שלך). סוכן על Agents API יכול לקרוא ל-generate_episode בלי שכבת תיווך. ויותר מזה: זו ולידציה שהימור ה-MCP שלך היה נכון — OpenAI בונה את התשתית המרכזית שלה סביב פרוטוקול שכבר מימשת לבד.

מענה

ארכיטקטורת "מתאם ראשי + סוכני-משנה", שאתה מריץ בעצמך עם שני הסוכנים, קיבלה מימוש רשמי. אם תרצה להעביר אוטומציות לתשתית מנוהלת, זו הדרך.

ראיונות

ישאלו איך בונים סוכן שרץ בפרודקשן. עכשיו יש לך שתי תשובות: "בניתי לבד" (מענה, פודקסטו) ו"אני מכיר את ה-harness המנוהל של OpenAI". נתון לזכור: SafetyKit דיווחו 60% ירידה בעלות ל-case אחרי מעבר ל-Agents API.

זהירות

בטא, והם אומרים שישנו מהר לפני GA. לא לבנות עליו משהו שלקוחות תלויים בו בלי fallback.

3 GPT-6 Astra: המודל שיושב עכשיו ב-Codex שלך
ממוקד קוד ו-computer-use. הלוסינציות ירדו מ-12.2% ל-4.2% — המספר החשוב לך כאן.
מאומת מול openai.com + InfoQ $10 קלט / $50 פלט למיליון

מה זה באמת

המודל החדש של OpenAI, ממוקד קוד ו-computer-use (הפעלת תוכנה דרך ממשק גרפי). יצא אתמול. ב-API הוא gpt-6-astra, ומתגלגל ל-ChatGPT Plus/Pro/Business/Enterprise.

  • מספרים (של OpenAI, במבחנים שלה): 57.9% ב-Terminal-Bench 4.0, 74.1% ב-DeepSWE, 72.6% ב-OSWorld 2.0 מול 65.7% ל-GPT-5.6 Sol.
  • הלוסינציות: 4.2% מול 12.2% אצל הקודם. בשבילך זה המספר החשוב ביותר בפריט, כי אתה מוודא כל פלט.
  • מחיר API: $10 למיליון טוקנים קלט, $50 פלט. יקר. מודל לכלי עבודה, לא ל-backend של מוצר.
  • הנקודה הכי רלוונטית לך: מנגנון ניסיוני ב-Codex שנותן לסוכן לשמור פתקים בין חלונות הקשר במקום להסתמך רק על compaction. חלונות קודמים נשארים searchable — בעבודת יום ארוכה על ריפו, דרישות ותוצאות טסטים מהבוקר לא הולכות לאיבוד אחרי הצהריים.

מה השתנה

קפיצה ב-computer-use ובסייבר (המודל הראשון שלהם שמסווג "קריטי" במסגרת הבטיחות, פחות רלוונטי לך). אזהרה אחת מהמקור עצמו: OpenAI מודה שה-reasoning הכתוב של Astra קשה יותר לניטור מקודמו — קשה יותר לבדוק "למה הוא עשה מה שעשה", וזה נוגע ישירות בסגנון ה-fact-checking שלך.

מה זה נותן לך

Codex

בעבודה היומיומית: שדרוג ישיר, בעיקר הפתקים בין-הקשריים.

ראיונות

שים לב שכל שלושת הפריטים ברדאר הזה הם מערכת אחת: GPT-Live-1 הוא הקול, Agents API הוא ה-harness, Astra הוא המוח. מי שמספר את זה כסיפור אחד בראיון נשמע כמו מי שבונה מערכות, לא כמו מי שקורא חדשות.

לא ל-backend

לא ל-backend של מענה או פודקסטו: $50 למיליון פלט זה ההיפך מ"כל שקל נספר".
